\problemname{Find the Missing Card}

Grandma wants to play a card game with you.
Before starting, she carefully checks whether the deck is complete.

The deck should contain $n$ cards labeled with unique numbers from $1$ to $n$.
However, after counting, Grandma discovers that exactly one card is missing.

Given the list of cards that are present, help Grandma determine which card is missing.

\section*{Input}
The first line contains a single integer $n$ ($1 \le n \le 1000000$), the number of cards that should be in the deck.

The second line contains $n-1$ distinct integers between $1$ and $n$, representing the cards that are present.

It is guaranteed that the integers are distinct and that exactly one integer between $1$ and $n$ (inclusive) is missing.

\section*{Output}
Output the number of the missing card.
